# Library-Management-System
Library Management System Developed By Java
**Note:**This project is currently a **Work in progress(WIP)**.Development and code updates are ongoing.

##Core Fatures(Current Stale)
The system includes secure login and operations for two distinct user roles:**Admin** and **User**.

**Admin Previlages**
-Add new books
-Delete books from the system
-Update existing book information
-List all available books
-Borrow and return books
-Search for books by ID,Author,Genre,and Language

**User Previlages**
-List all available books
-Borrow and return books
-Search for books by ID,Author,Genre and Language

## Technologies And Tools Used
**Language:**Java
**Data Storage:**File I/O (Persistent data tracking via 'books.txt')
